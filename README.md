# Brújula

Aventura educativa pixel art para jóvenes. Recorres un mundo de 19 regiones (sueño, estudio, atención, hábitos, emociones, dinero, ciudadanía…), cada una con su guardián, lecturas breves, escenas, retos en la vida real y trofeos que demuestran lo que has aprendido. Gratis, sin registro y privada: todo se guarda solo en tu dispositivo.

Abrir: https://rcanas-code.github.io/Brujula/
